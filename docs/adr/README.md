# Architecture Decision Records

This directory contains the initial Architecture Decision Records (ADRs) for the Enterprise Research Agent.

ADRs capture important architectural choices together with:
- the context that required a decision,
- the options considered,
- the selected approach,
- trade-offs,
- and conditions that may cause the decision to be revisited.

| 0002 | Use a modular monolith | Accepted |
| 0003 | Use PostgreSQL + pgvector | Accepted |
| 0004 | Calculate confidence outside the LLM | Accepted |
| 0005 | Use an AI provider abstraction | Accepted |
| 0006 | Defer asynchronous ingestion | Accepted |
